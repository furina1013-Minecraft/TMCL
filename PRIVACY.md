# TMCL Privacy Policy

TMCL is a local Windows Minecraft: Java Edition launcher.

## Data we handle

- Microsoft OAuth access and refresh tokens
- Minecraft profile name and UUID
- Local launcher settings, logs, and instance data

We do not collect Microsoft passwords.

## How data is used

- To authenticate the user with Microsoft/Xbox/Minecraft
- To launch the user's own Minecraft: Java Edition installation
- To refresh the login session when needed

## Storage and sharing

All tokens and settings are stored locally on the user's computer.
Tokens are encrypted with Electron safeStorage / the Windows credential store.
TMCL does not operate a server that receives or stores account tokens.
We do not sell, share, or transfer account data to third parties.

## Deletion

Users can remove an account from TMCL, which deletes the local saved tokens.
Uninstalling TMCL and deleting its data directory removes all local launcher data.
